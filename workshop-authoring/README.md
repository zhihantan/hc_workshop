# Workshop authoring

Facilitator-only source material for designing and maintaining the workshop.

- `agenda/` — editable workshop agenda.
- `story/` — canonical Unicorn Finance company and workshop narrative.
- `dataset/` — dataset design, schema references, participant-document sources, and ER assets.
- `prompts/` — reusable prompts for generating the section content.

Publish attendee-facing PDFs to `../participant-materials/` and runnable labs to `../workshop-content/`. Participants do not need this directory during the workshop.
